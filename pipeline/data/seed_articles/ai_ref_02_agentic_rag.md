# Agentic RAG 技术详解

> 来源: ai_reference | 可信度: 0.90

## 从传统 RAG 到 Agentic RAG

传统 RAG 是单步固定检索：用户提问 → 检索一次 → 拼接上下文 → LLM 生成。
Agentic RAG 是多步动态检索：规划器分解问题 → 检索器执行 → 推理器生成中间结果 → 验证器检查。

## 四大核心模块

1. 规划器：分解用户问题为多个子任务
2. 检索器：支持向量检索、图检索、网络检索
3. 推理器：整合信息生成中间结果
4. 验证器：验证准确性，错误则重新检索

## 关键技术

- GraphRAG：微软开源的图检索增强技术，实现多跳推理
- 混合检索：BM25 + 向量检索 + 重排序
- 动态多轮检索：根据中间结果决定是否继续检索
- 自我修正：检索结果不理想时自动改写查询重新检索
