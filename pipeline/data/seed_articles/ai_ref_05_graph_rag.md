# GraphRAG 技术原理

> 来源: ai_reference | 可信度: 0.90

## 什么是 GraphRAG

GraphRAG 是微软开源的一种图检索增强生成技术，利用知识图谱的结构化关系来增强 LLM 的检索能力。与普通 RAG 的区别在于：GraphRAG 通过实体和关系图进行多跳推理。

## 核心流程

1. 实体抽取：使用 LLM 从文档中提取实体和关系
2. 图谱构建：构建实体-关系知识图谱
3. 社区检测：识别图中的实体社区
4. 摘要生成：为每个社区生成摘要
5. 查询时：向量检索 + 图遍历邻居实体 → 融合重排

## 优势场景

- 实体关联类问题：Python 数据科学生态有哪些常用库
- 报错溯源类问题：某个报错与哪些 API 和版本相关
- 多跳推理：A 依赖 B，B 依赖 C，A 最终依赖什么

## 实现方案

轻量方案：jieba 词性标注 + 共现矩阵 + 一跳扩散（适合 demo 规模）
重量方案：Neo4j + LLM 抽取 + 社区检测（适合生产规模）
