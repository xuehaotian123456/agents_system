# DevPilot — 智能技术助手 项目分析报告

## 一、项目概述

**DevPilot** 是一个基于 LangGraph 的智能技术助手系统，能够自动爬取技术文章、构建知识库、通过四节点 Agent 闭环回答技术问题。项目完全自建，无教程依赖，面向真实使用场景。

- **项目地址**: E:\track_exp\tech_agent\
- **Python 环境**: rag_env (conda)
- **启动命令**: `streamlit run app.py`

## 三、核心架构

### 3.1 LangGraph 四节点 Agent 图

```
用户提问
    │
    ▼
┌──────────┐
│ Planner  │  分析意图 → 制定计划 → 选择工具
└────┬─────┘
     │
     ├── requires_search=false ──► Summarizer（简单对话直接回答）
     │
     ▼ requires_search=true
┌──────────┐
│Retriever │  执行 RAG 检索 + 工具调用
└────┬─────┘
     │
     ▼
┌──────────┐     retry (confidence < 0.5)
│Reflector │ ───────────────────────────────► Retriever
└────┬─────┘      (最多重试 2 次，每次改写查询)
     │ pass
     ▼
┌──────────┐
│Summarizer│  综合信息 → 结构化回答
└──────────┘
     │
     ▼
   用户
```

**为什么必须用 LangGraph 而不是 Chain？**

- **条件路由**: Planner 根据意图决定是否走检索路径，简单对话直接回答
- **回环重试**: Reflector 判定质量不够 → conditional edge 回到 Retriever，重写查询
- **状态持久化**: TypedDict + Annotated reducer，每个节点的状态变化可追踪
- **可视化**: `graph.get_graph().draw_mermaid()` 一键生成架构图

### 3.2 知识图谱构建管线

```
技术文章(Markdown)
    │
    ▼
RecursiveCharacterTextSplitter (chunk_size=300, overlap=30)
    │
    ▼
jieba.posseg 词性标注 → 只保留名词/专名/英文
    │
    ▼
100+ 中文停用词过滤 + 2字长度过滤 + 纯数字过滤
    │
    ▼
文档块内共现矩阵构建（同一 chunk 内实体两两 +1）
    │
    ▼
IDF 过滤: 出现在 >30% chunk 的泛化词自动移除
    │
    ▼
KG 就绪: entity_to_chunks + co_occurrence + entity_freq
    │
    ▼
提供: get_entity(实体查询) + one_hop_expand(一跳扩散) + search(关键词搜索)
```

**为什么不用 Neo4j？**
- 零外部依赖，适合 10k 以下实体规模
- 部署简单（一个 Python 文件搞定）
- 面试讲得通：自定义了构建管线的每一步

### 3.3 混合检索

```
查询 "Python 异步编程"
    │
    ├─► 向量语义 (ChromaDB + DashScope embedding)
    │   返回: 语义最相关的文档块
    │
    ├─► BM25 关键词 (jieba 分词 + rank_bm25)
    │   返回: 精确包含 "Python" "异步" "编程" 的文档块
    │
    ├─► KG 实体扩散 (one_hop_expand)
    │   从 "Python" → 扩散到 "asyncio" "async" "协程"
    │   附加扩散词到检索查询
    │
    ▼
合并去重 → BGE-Reranker CrossEncoder 重排序 → Top-K 结果
```
